# Reportar problemas de seguridad

El MVP 0.1.x está en desarrollo y no ofrece un compromiso de tiempos de respuesta. No está preparado para un despliegue ciudadano público.

No publiques claves ni datos de ciudadanos en issues, PRs o comentarios. Si la opción **Report a vulnerability** está disponible en la pestaña Security de GitHub, úsala para un reporte privado. Si no está habilitada, abre un issue únicamente para pedir al mantenedor un canal privado, sin detalles explotables, datos personales ni secretos.

Incluye en el canal privado: versión, impacto, pasos reproducibles con datos ficticios y mitigación sugerida. Nunca adjuntes credenciales válidas. Ante una clave expuesta, revócala primero en el proveedor.

Controles y límites: [docs/SEGURIDAD-PRIVACIDAD.md](docs/SEGURIDAD-PRIVACIDAD.md).
